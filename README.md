# pandas Map Viewer

This is a simple command-line application to view `.map` files, written in Python with pandas.

## Dependencies

To run this application, you will need to have Python installed, as well as the `pandas` library. You can install this library using pip:

```bash
pip install pandas
```

## Usage

To use the map viewer, run the following command in your terminal:

```bash
python pandas_map_viewer.py <path_to_map_file>
```

Replace `<path_to_map_file>` with the actual path to your `.map` file.

### Example

```bash
python pandas_map_viewer.py test.map
```
